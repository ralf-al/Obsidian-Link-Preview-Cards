# Link Preview Cards

Turn pasted URLs into clean, clickable preview cards in Obsidian.

## Demo

![Link Preview Cards demo](./docs/demo.gif)

## What it does

- Paste a URL with no selection -> inserts a rich preview card.
- Keep Obsidian default paste behavior when text is selected.
- Pulls title, description, image, site name, and optional author metadata.
- Falls back to favicon when no Open Graph image is available.
